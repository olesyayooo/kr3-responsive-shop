# ShopProject — контрольная работа №3

Адаптивный HTML/CSS-магазин на основе исходников КР №1, без Bootstrap.

## Страницы
- `index.html` — главная и популярные товары
- `catalog.html` — каталог и фильтры (в исходном проекте фильтры демонстрационные)
- `product.html` — динамическая карточка товара и таблица
- `order.html` — форма заявки
- `contacts.html` — контакты и форма обратной связи
- `about.html` — дополнительная страница компании

## Адаптивность
- Отдельный `css/responsive.css`, подход Mobile First
- Контрольные ширины для проверки: 360, 430, 768, 1024, 1440 px
- Grid для карточек и каталога, Flexbox для меню и кнопок
- Адаптивные изображения с `srcset`/`sizes` и ограничением ширины
- Таблица характеристик прокручивается внутри контейнера
- Формы и кнопки перестраиваются на мобильных экранах

## Доступность (практическая №13)
- Ссылка «Перейти к основному содержимому» на всех страницах
- Семантические `main`, `nav`, заголовки, `aria-current` для активной страницы
- Видимый `:focus-visible` и подписи `label` у полей
- Alt-описания изображений, названия модального окна
- Уменьшение анимации при `prefers-reduced-motion`

## Lighthouse
Откройте проект в Chrome, запустите DevTools → Lighthouse → Accessibility для `index.html`, `catalog.html`, `order.html`. Сохраните настоящий HTML-отчёт или скриншот в `lighthouse/`. **Аудит пока не запускался; балл и отчёт не выдуманы.**

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер (`python3 -m http.server 8000`).

## Примечания
Изображения устройств в архиве — самостоятельно созданные схематичные заглушки, так как оригинальные PNG не были загружены. Формы демонстрационные, без отправки на сервер.
